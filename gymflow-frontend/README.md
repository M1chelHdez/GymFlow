# GymFlow — Frontend

Interfaz web desarrollada con Angular 20, TypeScript y SCSS.

## Requisitos
- Node.js y npm compatibles con Angular 20.
- Backend Spring Boot iniciado en `http://localhost:8080`.
- PostgreSQL disponible para el backend.

## Ejecutar
```bash
npm install
npm start
```
Abre `http://localhost:4200`.

## Build
```bash
npm run build
```

La interfaz consume la API REST de GymFlow. Consulta el README raíz para iniciar PostgreSQL/backend, configurar credenciales, ejecutar pruebas y conocer las limitaciones funcionales de la demo.
